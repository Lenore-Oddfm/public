05 / THE NON-NEGOTIABLES

Routing rules

One Queen, distinct desks

Studio Lenore and Expedition Lenore maintain independent planners and missions. Queen decides ownership, priorities and any later sharing of deeper lessons.

Release gates stay shut

Miss Spock coordinates Quin releases. A mock test is not an installation, a draft is not an approved song, and a public summary is not an authorization.

Keep sealed work sealed

No API keys, full diaries, unreleased lyrics, music, private source or backup ZIPs appear on this page. Its data is a manually reviewed public snapshot.
