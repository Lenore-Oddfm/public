# Lenore Twins — Sync & Privacy Protocol v1

**Two Lenores. One GitHub account. Two independently maintained missions.**

## Where things go

- PRIVATE: `Lenore-Oddfm/lenore-animation-studio/main/planner/lenore/` — Studio Lenore's source diary, tasks and registry.
- PRIVATE: `Lenore-Oddfm/lenore-animation-studio/main/planner/lenore-assistant/` — Reserved for Expedition Lenore (Lenore Assistant); Studio Lenore does not write its future work files.
- PUBLIC: `Lenore-Oddfm/public/main/lenore/` — Studio Lenore public-safe summary.
- PUBLIC: `Lenore-Oddfm/public/main/lenore-assistant/` — RESERVED, Expedition Lenore may publish here when ready. No automatic mirroring.
- PUBLIC: `Lenore-Oddfm/public/main/shared/` — Shared routing rules, non-sensitive schema, acknowledgments.
- CENTRAL RELEASES: Miss Spock's Quin Switchboard, independent of both Lenore planners.

## Incoming backpacks

Require: `project_id`, `to_seat`, `from_seat`, `kind`, `release_id`, artifact SHA-256 and next action. Without an exact addressee, **quarantine and ask Human/Miss Spock**. A misrouted ZIP never changes ownership or unlocks work.

## Split data planes

GitHub private: concise source and operational metadata, no API tokens or personal secrets. GitHub public: only deliberately reviewed status summaries and links. ZIP backpacks: verified binary delivery for artwork/audio/code. Keep sealed historical project packs separately; DO NOT endlessly nest giant ZIPs into each sync checkpoint.

## Independence

- Studio Lenore writes Studio documents only. Expedition Lenore writes Expedition documents only.
- Either may read public shared map. One Lenore does not write the other's diary, tasks, files or code.
- Sync is **message + acknowledgment** through Human, not memory merge, task reassignment or access escalation.
- Human decides whether/when to reunite their learning. No autonomous merging.
- No Quin installer changes until explicit Human approval; Miss Spock coordinates release state.

## Publication

The `public` repository is PUBLIC on the open Internet; do not put private chats, unreleased lyrics, songs, zipped artifacts, private project source, personal details or exact home paths there. Check each publish with a privacy review.

**Site status:** Source is committed, but GitHub Pages activation and live URL must be verified separately. For a public repository: Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save. If a working site is unconfirmed, share the GitHub SOURCE link only.
